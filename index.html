Official Internship Report Abstract

This internship report presents the design, implementation, and evaluation of Seismic Viewer, an interactive desktop application for the spatial and temporal visualisation of seismic data. The system was developed during an internship at the INGV to address a limitation of existing tools: the lack of software capable of displaying large earthquake datasets while integrating spatial clustering and geological plane estimation. Seismic Viewer combines a Python backend for data processing with a WebGL frontend for 3D graphics in an interactive desktop window. The binary streaming protocol achieved an 80% size reduction compared to JSON, and the plane fitting pipeline estimated strike and dip angles with a mean error below 1.0° under realistic noise conditions on Campi Flegrei seismic swarms.

Scientific Backend & Algorithms (Python)
  • Core Engine: Python 3.11, FastAPI, NumPy, SciPy, Scikit-learn
  • Fault Fitting: RANSAC with Singular Value Decomposition (SVD) refinement (< 1.0° error)
  • Clustering: DBSCAN & MiniBatchKMeans with Global Label Matching for temporal color consistency
  • Binary Streaming: Custom binary buffer reducing JSON payload by 80%
3D Interactive Frontend & GIS
  • Rendering: Hardware-accelerated WebGL with Plotly.js at constant 60 FPS
  • Georeferencing: Spherical latitude scaling correction below the terrain
  • 4D Scrubbing: Fluid interactive temporal playback with depth/magnitude filters
  • Geophysics: INGV GOSSIP API, crustal Vp/Vs tomography, GNSS ground uplift
